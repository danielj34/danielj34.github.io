01RTL / VERIFICATION / FPGA

Independent project · 2026

RV32I CPU

Source & testbench ↗

A synthesizable, single-cycle RV32I CPU in SystemVerilog. I checked the register writes, memory strobes, and branch targets against the instructions being executed.

What I built

A 32 × 32-bit register file, ALU, decoder, immediate generator, branch and jump logic, and separate instruction/data-memory interfaces. A Python encoder turns test programs into instruction words.

How I checked it

Self-checking cocotb/Verilator regressions examine execution cycle by cycle, including signed comparisons, byte-store lanes, jump links, misaligned accesses, and precise traps.

02CLIENT-CENTRED / ELECTROMECHANICAL

Assistive grabber · Controller PCB design

ESP32 grabber controller

PCB DESIGN
REVISION A

A two-layer controller-board design for the assistive-grabber concept. It brings an ESP32 DevKitC, a socketed dual motor-driver module, button inputs, and separate motor power onto one carrier PCB. The board separates the control connections and motor-power routing, with a removable standby-enable link.

PROJECT ARTIFACTS
Download editable PCB package ↓Altium import file (.PCB) ↓Connection schematic ↗

The controller architecture

The carrier uses an ESP32 DevKitC and a socketed SparkFun TB6612FNG module. It separates USB-powered logic from the fused motor supply, provides two motor outputs, and exposes OPEN, CLOSE, and STOP inputs. A pulldown holds the driver in standby when the removable enable link is open.

The board design

A 111.76 × 86.36 mm layout with 16 component placements, 19 nets, and 36 through vias. Motor routing is 1.00 mm, logic/ground routing 0.50 mm, and control signals 0.30 mm. The native layout reports zero violations and zero unconnected items under its default-rule check.

The wider grabber project

The original ENGINEER 1P13 team project developed a wheelchair-mounted grabber around limited hand dexterity and reach. My work included concept development, embedded/PCB prototyping, and electromechanical integration. The team iterated three prototypes.

The completed team prototype used a simpler 2P2T switch circuit after reliability and usability problems with the initial electronics. The PCB is presented here as a design project. CAD views and the engineering drawing show the team’s mechanical design.
